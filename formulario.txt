- ¿Cuándo se usa for y cuándo while?
    - Ambos se pueden usar indistintamente, funcionan igual
    - For es para ciclos definidos y While para ciclos indefinidos
    - While es para cuando el usuario ingresa información y For cuando hay parámetros
    - For es solo para rangos, while para el resto de ciclos
